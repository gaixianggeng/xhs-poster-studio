# 小红书封面生成器

一个零依赖的小红书「实测笔记」封面生成器，固定输出 1080 × 1440 的 3:4 图文封面。骨架固定：报告头、主词、两行标题、实测条件、证据窗、结论章、页脚；每篇只换文案、证据和配色，主页因此保持统一。

截图和临时加入的对比封面只在当前浏览器内存中处理，不会上传或写入 `localStorage`；刷新页面后需要重新选择。

> 当前部署入口与运维方式见[部署说明](./docs/DEPLOYMENT.md)。

## 目录与使用入口

本目录只保存封面网站。小红书笔记、素材、数据和复盘位于同级独立项目 [xiaohongshu-operations](../xhs-poster-studio/README.md)。网站导出的 PNG 可放入该项目的单篇笔记目录。

单篇封面、正文或发布截图放入运营项目，不放在网站的 `assets/`。

## 功能

- 固定生成小红书图文封面 `1080 × 1440 px`、3:4 竖版 PNG；海报预览、主页双列预览和导出共用同一次 Canvas 渲染。
- **固定骨架**，从上到下：
  1. 报告头：左侧深色胶囊（默认「FIELD NOTE · 实测记录」），右侧「系列 · 日期」。
  2. 主词：一个产品名或数字，主色超大字，按宽度自动缩小；可加一个中文后缀，例如「393 个专家」。
  3. 两行标题：用【】标出唯一的关键词，关键词放进主色胶囊；超宽时整体缩小，不截断。
  4. 实测条件胶囊：每行一个，最多 3 个，白色 / 底带色 / 点缀色轮换。
  5. 证据窗：白底圆角，跨在上下两块颜色之间，只放一个证据。
  6. 结论章：波浪饼干形，斜盖在证据窗右上角，写一句话结论；留空不显示。
  7. 页脚：用「｜」分隔左右两段。
- **6 种证据类型**：截图、步骤、分层、对比、评分、大字。各类型的内容分开保存，切换类型不会清掉已写的内容；截图在海报预览上拖动即可调整取景。
- **6 套配色**（樱粉、薄荷、青柠、天蓝、薰衣草、杏黄），参考 Android 16（Material 3 Expressive）的配色思路：浅色底 + 另一色底带 + 同色系深色文字 + 一个高饱和主色 + 一个点缀色。色值为自行调配，不是官方色板。
- **深浅两档**：「封面 · 深一档」把底色和底带加深一级，在白色信息流里更突出；「内页 · 标准」保持浅色，适合第 2 张以后的配图。其余颜色两档相同。
- 主词旁的花瓣与四叶草贴纸可关闭；主词伸到贴纸位置时自动不画对应贴纸。
- 6 张示例来自已发布或已定时的笔记，覆盖评分、步骤、对比（2 张）、分层、大字 5 种证据；截图类型没有示例，直接上传自己的图。载入会整体替换文案，可以撤回。
- 主页预览可加载 3 张已发布封面快照、用当前文案生成的 6 套配色，或本地旧封面，判断新封面与账号已有内容是否协调；这些对比数据不会保存或上传。
- 文案和样式保存在浏览器 `localStorage`；截图和对比封面只保存在当前页面内存，刷新后需要重新选择。
- 字体只用系统字体（主词 Arial Black，中文苹方 / 雅黑，等宽 SF Mono / Menlo），不依赖外网字体服务。

## 本地运行

```shell
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。
