# 小红书封面生成器

一个零依赖的小红书封面生成器，固定适配 1080 × 1440 的 3:4 图文封面。内置“对话工作台、编号清单、证据图文、编辑杂志、模型发布”五种构图，支持独立配色、本地照片、真实主页对比、实时编辑和高清 PNG 导出。

照片和临时加入的历史封面只在当前浏览器内存中处理，不会上传或写入 `localStorage`；刷新页面后需要重新选择。

> 当前状态：MVP 已完成，暂时通过服务器 IP 提供访问；正式域名等待完成备案或火山引擎接入备案。

## 功能

- 固定生成小红书图文封面 `1080 × 1440 px`、3:4 竖版 PNG。
- 按阅读节奏提供五种结构化构图：
  - 对话工作台：问题标题配 Prompt 卡片，适合问答、观点和需求拆解。
  - 编号清单：标题配步骤轨道，适合教程和收藏型内容。
  - 证据图文：结论先读，单张产品图或结果截图做佐证。
  - 编辑杂志：手绘思考线稿、分隔线和衬线标题分区，适合专题与长文导读。
  - 模型发布：大图、超大版本号和标题形成发布感，适合模型、产品与版本更新。
- 每种构图都有一份按版式反推的“模板原稿”，逐项说明角标、上方副标题、主标题、下方副标题和底部文字在该模板中的角色、建议字数与换行方式。
- 第一次切换到某个模板会载入它的模板原稿；改写后再次返回会恢复该模板自己的文案草稿。已有文案不会在升级时被覆盖，也可通过“载入最佳示例 / 恢复载入前文案”安全对照。
- 构图、内容呈现和配色彼此独立；切换构图会保留照片和当前配色，避免把模板与颜色绑死。
- 内容呈现提供“纯文字、图文佐证、大图主导”三种模式；没有上传照片时使用本地示例图帮助判断构图，上传后立即替换。
- 字体类型和配色直接可选，精确 HEX、标题/正文字体拆分、字号和间距保留在高级微调区。
- 支持主副标题、角标、底部文字、字号、间距和对齐调整；卡片宽高与圆角固定，保持主页风格统一。
- 字体提供标准黑体、现代黑体（Grotesk）、圆润标题、自然手写和编辑衬线五类快捷预设；对话、清单、证据和发布默认现代黑体，编辑杂志默认衬线主标题与现代黑体正文；内置 Yozai Medium 仅在选中时加载。
- 主标题会把过长的展示行自动拆成最多 3–4 行，并从内容安全区顶部开始排版；最后一行自动作为重点强化，长行只缩小自身，让主标题优先占用可用空间。
- 配色收敛为 10 组，每组同时定义画布、卡片、文字和视觉区域四个颜色角色；新增 OpenAI 黑白与 Claude 暖黑两组官网风格灵感色，同一构图仍可独立换色。
- 支持选择一张不超过 20 MB 的本地照片；“调整区域”用于移动照片模块和拖动四角改变大小，接近画布水平或垂直中心时显示参考线并吸附；“调整取景”用于在固定区域内直接拖动照片内容选择展示部分。
- 图文模式会展示“选择呈现 → 上传照片 → 在预览拖动调整”的操作路径；照片和取景状态只在当前页面处理，不写入持久化数据。
- 海报预览、双列主页预览和 PNG 导出复用同一个 Canvas 渲染结果。
- 主页预览可一键加载 3 张当前发布封面快照和 5 种实时 Canvas 预设，也可加入本地旧封面，用于判断新封面与账号已有内容是否协调；这些对比数据不会保存或上传。
- 文案和版式保存在浏览器 `localStorage`；照片仅保存在当前页面内存。

## 本地运行

```shell
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。
