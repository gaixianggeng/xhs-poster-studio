# 小红书封面生成器

一个零依赖的小红书封面生成器，固定适配 1080 × 1440 的 3:4 图文封面。内置“经验 / 观点、教程 / 清单、产品 / 实测、深度文章”四类品牌预设，支持本地照片、真实主页对比、实时编辑和高清 PNG 导出。

照片和临时加入的历史封面只在当前浏览器内存中处理，不会上传或写入 `localStorage`；刷新页面后需要重新选择。

> 当前状态：MVP 已完成，暂时通过服务器 IP 提供访问；正式域名等待完成备案或火山引擎接入备案。

## 功能

- 固定生成小红书图文封面 `1080 × 1440 px`、3:4 竖版 PNG。
- 按笔记目的提供四类结构化预设：
  - 经验 / 观点：米白绿纯文字，作为日常主力。
  - 教程 / 清单：午夜蓝配截图证据，强化步骤感和收藏感。
  - 产品 / 实测：珊瑚橙大图优先，适合真实产品图或使用结果。
  - 深度文章：上方视觉、下方衬线标题的编辑博客结构，适合专题复盘。
- 默认锁定当前类型的品牌版式；字体类型和配色直接可选，精确 HEX、标题/正文字体拆分、字号和间距放在可收起的“高级微调”中。
- 支持主副标题、角标、底部文字、字号、间距和对齐调整；卡片宽高与圆角固定，保持主页风格统一。
- 字体提供标准黑体、现代黑体（Grotesk）、圆润标题、自然手写和编辑衬线五类快捷预设；经验、教程和产品默认现代黑体，深度文章默认衬线主标题与现代黑体正文；内置 Yozai Medium 仅在选中时加载。
- 主标题字号会根据当前手动换行、横向宽度和照片版可用高度计算真实上限，避免滑杆进入视觉不变化的无效区间。
- 完整保留原有十套配色，并新增黑字纸白、森林鼠尾草、梅子玫瑰、墨绿薄荷、石墨银和咖啡奶油六组低噪配色。
- 支持选择一张不超过 20 MB 的本地照片；“调整区域”用于移动照片模块和拖动四角改变大小，接近画布水平或垂直中心时显示参考线并吸附；“调整取景”用于在固定区域内直接拖动照片内容选择展示部分。
- 照片提供“文字海报”和“专辑焦点”两种版式：前者标题优先，后者参考音乐分享卡片的大幅封面与标题、副标题结构。
- 海报预览、双列主页预览和 PNG 导出复用同一个 Canvas 渲染结果。
- 主页预览可临时加入最多 8 张旧封面，用于判断新封面与账号已有内容是否协调；这些图片不会保存或上传。
- 文案和版式保存在浏览器 `localStorage`；照片仅保存在当前页面内存。

## 本地运行

```shell
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。
