# 小红书封面生成器

一个零依赖的小红书大字报生成器，支持实时编辑文案与配色、切换常用画布尺寸、预览双列信息流效果并导出高清 PNG。

> 当前状态：MVP 已完成并上线，可继续迭代。

## 本地运行

```shell
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。
