# 小红书封面生成器

一个零依赖的小红书封面生成器，固定适配 1080 × 1440 的 3:4 图文封面。只有一种版式，通过模块开关与槽位组合出不同呈现；支持独立配色、本地照片、真实主页对比、实时编辑和高清 PNG 导出。

照片和临时加入的历史封面只在当前浏览器内存中处理，不会上传或写入 `localStorage`；刷新页面后需要重新选择。

> 当前状态：MVP 已完成，暂时通过服务器 IP 提供访问；正式域名等待完成备案或火山引擎接入备案。

## 功能

- 固定生成小红书图文封面 `1080 × 1440 px`、3:4 竖版 PNG。
- **内容优先的流程**：写文案 → 选呈现与模块 → 配色 → 字体 → 排版微调。任何一步都不会替换或清空你已经写好的文字。
- 只有一种版式（结论先读，图片或超大编号做证据），变化交给模块与配色：
  - **模块开关**：角标、上方副标题、下方副标题、超大编号、底部文字各自可开可关。关掉只是不渲染，**输入框里的文字原样保留**，随时开回来。主标题不提供关闭。
  - **槽位**：主视觉可放在标题上方或下方；下方副标题同样可以移到标题上方。位置之外不做自由拖拽，卡片骨架固定，主页才保持统一。
  - 模块开着但对应字段为空时，控件上会标出「该字段为空」，不会让人误以为是故障。
- 一份“写法参考”逐项说明角标、上方副标题、主标题、下方副标题和底部文字的角色、建议字数与换行方式；同一份规则和示例直接显示在每个输入框上，完整清单折叠在“逐字段规则与示例”里。
- 主标题带实时字数与行数提示，超出建议区间会变色，但不阻止输入。
- “载入示例文案”会整体替换当前文案，可用“恢复载入前文案”一键撤回。除此之外没有任何操作会动你的文字。
- 默认配色为青绿墨底；配色只能整套选择，不提供逐项改色。
- 主视觉呈现提供“纯文字、图在标题下方、图在标题上方”三种；没有上传照片时使用本地示例图帮助判断构图，上传后立即替换。
- 字体类型和配色直接可选；标题/正文字体拆分、字号和间距保留在排版微调区。颜色只能从预设配色里选，不提供逐项改色；“编辑蓝”的珊瑚橙只用于固定边缘标记，不能被拆开手调。
- 支持主副标题、角标、底部文字、字号、间距和对齐调整；卡片宽高与圆角固定，保持主页风格统一。
- 字体提供标准黑体、现代黑体（Grotesk）、圆润标题、自然手写和编辑衬线五类快捷预设；科技感由现代黑体、留白与色面承担，不再额外引入像素字体。
- 主标题会把过长的展示行自动拆成最多 3–4 行；最后一行自动作为重点强化，长行只缩小自身，让主标题优先占用可用空间。
- 眉题、主标题和副标题之间的富余空间只拿外侧留白的一小部分，文字收成一组而不是各自飘着；超大编号在纯文字模式下放大到几乎撑满主视觉区，有照片时落在一块卡片色标牌上，两种情况都是深色字。
- 主标题字号滑杆的右端就是当前文案真正能生效的上限，不存在“拖到底也没变化”的空行程；旁边的“放到最大”一键跳到该上限。读数显示的是画布上的实际字号，分行字号同样显示实际值。
- 排版节奏提供“紧凑 / 标准 / 宽松”三档，一次调好行距、组间距和上下副标题字号；“标准”回到当前模板的推荐排版。
- 全部 17 组配色一律使用深色文字：白字在小红书双列缩略图里冲击力不足，因此电光蓝和纯黑白都改成浅卡承深字，浅纸彩卡的卡片也提亮到能承载黑字。配色包含深底高对比 7 组、满幅色场 6 组、浅纸彩卡 4 组：
  - 深底高对比（青绿、橙红、柠檬、电光蓝、纯黑白、紫罗兰、品红）：近黑画布配单一高饱和亮卡，取自账号已发布封面的实际取色，缩略图冲击力最强。
  - 满幅色场（仙人掌绿、石楠紫、陶土橙、晴空蓝、橄榄绿、编辑蓝）：accent 铺满画布、象牙卡承载文字、近黑负责所有墨线；编辑蓝额外保留一处固定珊瑚橙边缘标记。
  - 浅纸彩卡（砖红纸、墨绿纸、靛蓝纸、深梅纸）：浅纸铺满画布，彩卡承载全部文字，靠浅底上的彩卡在白色信息流里形成识别。
- 颜色角色拆成画布、卡片、文字、媒体块底色和墨线五项；媒体块里的墨色按块底色自动选，不会出现近黑线画在深色块上。accent 与象牙卡明度过近时自动补一条墨色细边，保证卡片轮廓在白色信息流里不消失。
- 支持选择一张不超过 20 MB 的本地照片；“调整区域”用于移动照片模块和拖动四角改变大小，接近画布水平或垂直中心时显示参考线并吸附；“调整取景”用于在固定区域内直接拖动照片内容选择展示部分。
- 图文模式会展示“选择呈现 → 上传照片 → 在预览拖动调整”的操作路径；照片和取景状态只在当前页面处理，不写入持久化数据。
- 海报预览、双列主页预览和 PNG 导出复用同一个 Canvas 渲染结果。
- 主页预览可一键加载 3 张当前发布封面快照和 3 种模块组合（用你当前的真实文案渲染），也可加入本地旧封面，用于判断新封面与账号已有内容是否协调；这些对比数据不会保存或上传。
- 文案和版式保存在浏览器 `localStorage`；照片仅保存在当前页面内存。

## 本地运行

```shell
python3 -m http.server 4173
```

打开 `http://127.0.0.1:4173/`。
